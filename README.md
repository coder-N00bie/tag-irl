# Tag IRL

Multiplayer tag in real 360° street photos. One player is the tagger, everyone else runs. Grab items (radar, map, speed potion, freeze bomb, cloak, shield, warp, ink bomb, pounce), and add bots if friends aren't around.

- Street photos: [Panoramax](https://panoramax.fr) contributors (CC BY-SA), shown with Pannellum
- Map: © OpenStreetMap contributors, via Leaflet
- Multiplayer: Supabase Realtime (broadcast + presence)

Static site, no build step: open `index.html` through any web server.
